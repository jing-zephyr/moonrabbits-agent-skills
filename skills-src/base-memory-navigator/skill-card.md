# skill-card · base-memory-navigator

|---|---|

| **中文名** | 基座记忆导航 |
| **版本** | 0.2.0 |
| **一句话** | 开工前先问后读，用最经济的方式对齐共享记忆——先问一句，不搜全盘 |
| **Owner** | zephyr 队 |
| **License** | Apache-2.0 |

## 做什么 / 给谁用

| 做什么 | 给谁用 |
|---|---|
| 新会话开工：先问用户"需要读共享记忆吗/知道在哪吗"，按索引层读取（<30KB），只点开相关 1–2 份 | 多窗口协作的 Agent 会话 |
| 需要大文件/资产本体前：先报告大小与用途，获批才读 | 任何要碰大资产的会话 |
| 开工前复述对齐（≤3 点），以用户说法为准 | 甲方在场时的对齐 |

**定位说明**：本技能是"上下文经济学"的可执行版——官方口径「常驻 ≈100 token/技能，没有人全装 343 个技能，按需安装 + 目录路由才是工程正解」，本技能把"读索引不读资产"做成纪律。它是本套件的早期试水件，非主链路。

## 依赖

| 类型 | 依赖 |
|---|---|
| 数据 | 无（由使用方提供记忆基座路径） |
| 模型 | 无（纯方法技能，不调用模型） |

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| 误用于"信息已齐"的任务 | 负触发：信息齐就直接干活，不问基座（用例 neg-1） |
| 索引里找不到就猜 | 硬约束：**问用户，禁止编造路径或假装读过**（用例 neg-3） |
| 大文件未经许可就读取 | 硬约束：先报告大小与用途，获批才动（用例 pos-3） |

## 部署地域（Deployment Geography）

| 项 | 说明 |
|---|---|
| 适用地域 | 全球（无地域限制） |
| 推理位置 | 无需推理 |
| 数据留存 | 无持久化 |

| 敏感数据 | 不读取记忆基座之外的任何路径 |
