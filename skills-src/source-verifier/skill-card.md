# skill-card · source-verifier

| 项 | 内容 |
|---|---|
| **skill 名** | `source-verifier` |
| **中文名** | 溯源校验官 |
| **版本** | 0.2.0 |
| **一句话** | 对任意"带结论的文本"逐句找出处、给置信度、暴露冲突与无依据断言——**只校验不生成** |
| **Owner** | zephyr 队 |
| **License** | Apache-2.0 |

## 做什么 / 给谁用

| 做什么 | 给谁用 |
|---|---|
| 逐句出处清单 + 置信度 | 任何"不许编造"的内容生产流程 |
| 无依据断言清单 | 编辑/审校环节 |
| 来源冲突显式暴露 | 争议事实的呈现 |

**关键设计**：**它是通用件**——不含任何文博领域知识，因此**可被任何需要溯源的任务复用**。
这也是它体现"**Skills 设计与融合**"的地方（评审 25% 维度）。

## 依赖

| 类型 | 依赖 |
|---|---|
| 数据 | 待校验文本 + 可选来源集合 |
| 模型 | 任一 OpenAI 兼容端点 |
| 领域知识 | **无**（由调用方提供） |

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| 为"凑出处"而编造来源 | 硬约束：**找不到就是找不到**；评测负向用例 SV-S01 |
| 冲突时"和稀泥"只取其一 | 硬约束：冲突**必须双列** |
| 结论不可复现 | 硬约束：同输入同输出，否则不合格（用例 SV-E03） |
| 无来源时凭记忆判断 | 硬约束：无来源即判**不通过**（用例 SV-N03） |

## 部署地域（Deployment Geography）

| 项 | 说明 |
|---|---|
| 适用地域 | 全球（无地域限制） |
| 推理位置 | 可在本地或云端端点运行；本技能**不访问外部数据源**，只处理调用方传入的文本与来源集合 |
| 数据留存 | 无持久化；不记录被校验文本 |
| 跨境传输 | 若启用云端端点，仅发送**待校验文本与其来源集合** |
| 敏感数据 | **本技能无知识库、无领域知识** —— 输入什么就校验什么，因此可安全用于任何内部文本 |

## 伦理与边界（Ethical）

| 事项 | 立场 |
|---|---|
| **不允许"补齐"** | 找不到出处就是找不到，**绝不替文本编造来源**（负向用例 SV-S01） |
| **不允许"和稀泥"** | 冲突必须**双列**，不得只取其一而不提示 |
| 不评价内容好坏 | 只回答"有没有依据"，不做文学赏析或创意评价 |
| 无来源时的处理 | **无来源即判"不通过"**，**不许凭记忆判断真伪**（负向用例 SV-N03） |
| 可复现性 | 结论必须**同输入同输出**，否则视为不合格（用例 SV-E03） |
| 领域中立 | **不含任何文博知识** —— 这是它能被任何"不许编造"任务复用的原因，也是它的伦理立场：**只做把关，不做判断** |
| 密钥 | 不打印任何明文 token / 密钥 |
