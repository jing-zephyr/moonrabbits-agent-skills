# source-verifier · 溯源校验官

> **只校验，不生成。** 这是它可被复用的原因——任何"不许编造"的任务都能挂上它。

## 一、输入与输出

**输入**：一段待校验文本 + 可选的知识库/来源集合。
**输出**：

```
【校验结论】   —— 通过 / 部分通过 / 不通过（三态，不用"大概/也许"）
【逐句出处】   —— 句子 → 来源 / 置信度(0-1) / 位置
【无依据断言】 —— 列出所有找不到出处的句子（**必须逐条列出，不许漏**）
【冲突清单】   —— 相互矛盾的两条（或以上）及其出处
【处理建议】   —— 对每条问题给出：删掉 / 改写 / 标注存疑 / 补来源
```

## 二、判定规则（**确定性规则，不靠感觉**）

| 情形 | 判定 |
|---|---|
| 每句都能找到出处，且无相互矛盾 | **通过** |
| 有个别句子无出处，但可标注存疑后保留 | **部分通过** |
| **核心结论**无出处，或出现来源冲突无法二选一 | **不通过** |
| 两条来源**年代差 > 50 年**且并存 | 标为**冲突**，两条都保留并提示 |
| 两条来源**置信度差 > 0.3** | 触发**二次验证**（找第三条来源） |
| 证据分 **< 0.6** | 判定**不通过**，建议**拒答** |

## 三、硬约束

1. **不允许"补齐"**：找不到出处就是找不到，**绝不替文本编造来源**；
2. **不允许"和稀泥"**：冲突必须显式列出，不得只取其一而不提示；
3. **不评价内容好坏**，只回答"有没有依据"；
4. **不打印**明文 token / 密钥；
5. 校验结论必须**可复现**（同一输入同一输出），否则视为不合格。

## 四、与其他 skill 的关系

| 关系 | 说明 |
|---|---|
| 被 `exhibit-narrative` **调用** | 作为叙事生成后的"最后一道闸" |
| 也可**独立使用** | 任何事实类文本都可送进来校验 |
| 它是**通用件**，不含文博领域知识 | 领域知识在调用方，校验规则在这里 |
