# skill-card · audience-adapter

| 项 | 内容 |
|---|---|
| **skill 名** | `audience-adapter` |
| **中文名** | 观众适配官 |
| **版本** | 0.2.0 |
| **一句话** | 同一份内容按观众画像换表达与详略——**只换表达，不换事实** |
| **Owner** | zephyr 队 |
| **License** | Apache-2.0 |

## 做什么 / 给谁用

| 做什么 | 给谁用 |
|---|---|
| 儿童 / 普通 / 专业 / 外语 四种画像改写 | 小程序面向不同观众 |
| 篇幅控制（一句话 / 展签 / 短讲述 / 讲解稿） | 不同展示位 |

## 依赖

| 类型 | 依赖 |
|---|---|
| 输入 | 原始内容 + **目标画像** + **目标篇幅**（缺一先问） |
| 上游 | `exhibit-narrative`（或任何产生内容的 skill） |
| 下游 | `source-verifier`（校验适配后是否仍句句有据） |

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| 借"丰富内容"之名**新增事实** | 硬约束：不新增事实；无来源则退回上游（用例 AA-N01） |
| 借"好听一点"之名**改变结论** | 硬约束：不改变结论（用例 AA-N02） |
| 压缩时**丢掉边界声明**（未找到/存疑） | 硬约束：边界声明必须随文保留（用例 AA-E02） |
| 画像不明就猜 | 硬约束：先问不猜（用例 AA-E01） |

## 伦理与边界（Ethical）

| 事项 | 立场 |
|---|---|
| **不新增事实** | 不得引入原文与出处之外的任何事实性陈述；无来源则**退回上游**（负向用例 AA-N01） |
| **不改变结论** | 原文说"存疑"，适配后**仍须存疑**（负向用例 AA-N02） |
| **不丢弃边界声明** | `未找到 / 存疑 / 非鉴定 / 非估价` 等标记**必须随文保留**（用例 AA-E02） |
| **压缩即舍弃** | 因篇幅删掉的句子，其出处须标注「未纳入本次输出」，**不得让其看似仍被支持** |
| 画像不明就问 | **先问，不猜**（用例 AA-E01）—— 猜错画像的代价是整段内容作废 |
| 翻译的诚实 | **不因翻译而弱化不确定性**（"可能为明代"不得译成断言式的 is from the Ming dynasty） |
| 不越权 | 需要考据或再创作的请求，**退回上游技能**，本技能不做 |
