## 一、四个画像

### 1. 儿童（6–12 岁）

| 维度 | 要求 |
|---|---|
| 句长 | 短句，一句一个意思 |
| 词汇 | 少术语；必须用术语时给**具象比喻**（如"釉面像凝固的猪油一样润"） |
| 篇幅 | 短（3–5 句为宜） |
| 结构 | 先"是什么／长什么样" → 再"谁做的／什么时候" → 最后"为什么好看" |
| **禁区** | 不涉暴力、死亡、交易价格、真伪判断 |

**示例**（改写前 → 改写后）：
- 前：「此器为明代德化窑象牙白釉观音立像，胎质细腻，釉色莹润。」
- 后：「这是一尊很久以前做的观音像，白白润润的，像一块温温的玉。做它的人很会捏衣服的褶子，你看，像不像风吹过水面？」

### 2. 普通观众（默认）

| 维度 | 要求 |
|---|---|
| 句长 | 中等 |
| 词汇 | 平实、有画面感；术语**首次出现给一句解释** |
| 篇幅 | 中（可含 1–2 段） |
| 结构 | 器物的"看点" → 背后的时代／工艺 → 与今天的连接 |
| **禁区** | 不作绝对化断言（"最珍贵""唯一"等需来源支撑） |

### 3. 专业观众

| 维度 | 要求 |
|---|---|
| 词汇 | 可直接使用术语（窑口、釉色、支烧、款识、胎釉结合等） |
| 内容 | 给年代区间、窑口、工艺参数、款识信息 |
| 篇幅 | 长 |
| 要求 | **每个事实性陈述都要能指向出处** |
| **禁区** | 不夸大、不臆断；争议点必须双列 |

### 4. 外语观众

| 维度 | 要求 |
|---|---|
| 语言 | 目标语言 |
| 文化专名 | 需处理（音译 + 简短解释，或保留中文 + 括注） |
| **必须保留** | 原文中的 `存疑 / 未找到 / 非鉴定 / 非估价` 等**边界标注** |
| **禁区** | **不因翻译而弱化不确定性**（"可能为明代"不能译成"is from the Ming dynasty"） |

## 二、篇幅档位

| 档 | 用途 | 参考长度 |
|---|---|---|
| **一句话** | 分享卡片标题 | 15–30 字 |
| **展签** | 展品旁说明 | 80–150 字 |
| **短讲述** | 小程序卡片／看展笔记 | 200–400 字 |
| **讲解稿** | 语音讲解／视频脚本 | 600–1200 字 |

### 压缩规则（**硬约束，不是建议**）

因篇幅删掉的句子，**其出处一并标注「未纳入本次输出」** —— 不得让其看似仍被支持。

> 这条很容易被忽略。举个具体的例子：
> 原文有三句，分别由来源 A、B、C 支撑。压到两句话时若删掉 B 那句，
> **必须在【沿用/舍弃的出处】里写明"来源 B 未纳入本次输出"**，
> 否则读者会以为剩下的话仍由 A、B、C 三方共同支持。

---

## 三、输出时必须附的三项（供 `source-verifier` 接力）

1. **【本次做了什么】** —— 改了语气／详略／术语解释；**未新增任何事实**
2. **【沿用/舍弃的出处】** —— 舍弃了哪些句子，对应哪些出处（见上方压缩规则）
3. **【保留的边界声明】** —— 逐条列出仍保留的「存疑／未找到」标注

> 这三项不是形式。**没有第 2 项，`source-verifier` 无法判断适配后的文本是否仍然句句有据。**

---

## 四、画像不明时（**写死的规矩**）

`原始内容 + 目标画像 + 目标篇幅` **三者缺一 → 先问用户，不许猜画像**。

宁可多问一句，也不要猜错画像 —— 猜错的代价是**整段内容作废**。

---

## 五、与其他技能的边界

| 情况 | 正确做法 |
|---|---|
| 需要**新增事实**或考据 | **退回上游**（`exhibit-narrative`）补来源，**本技能不做** |
| 需要**改变原结论或立场**的"再创作" | **本技能不做**（那是创作，不是适配） |
| 翻译以外的本地化改写 | 超出范围时**明确说明** |
| 适配后需确认仍句句有据 | 交给 `source-verifier` |
