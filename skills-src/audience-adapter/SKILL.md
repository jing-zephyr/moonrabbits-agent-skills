# audience-adapter · 观众适配官

> **铁律：只换表达，不换事实。** 任何需要"加点新东西"的请求，都要退回上游 skill 补来源。

## 一、支持的观众画像（可扩展）

| 画像 | 语言特征 | 详略 | 禁区 |
|---|---|---|---|
| **儿童**（6–12） | 具象比喻、短句、少术语 | 短 | 不涉暴力/死亡/交易细节 |
| **普通观众** | 平实、有画面感、术语首次出现给解释 | 中 | 不作绝对化断言 |
| **专业观众** | 可用术语，给年代/窑口/工艺参数 | 长 | 不夸大、不臆断 |
| **外语观众** | 目标语言，文化专名处理需说明 | 中 | 不丢失"存疑/未找到"的标注 |

## 二、输入与输出契约

**输入**：`原始内容 + 目标画像 + 目标篇幅`（三者缺一 → **先问用户**，不许猜画像）
**输出**：

```
【适配后文本】
【本次做了什么】   —— 改了语气/详略/术语解释；**未新增任何事实**
【沿用/舍弃的出处】 —— 舍弃哪些句子（如因篇幅），对应哪些出处也一并舍弃
【保留的边界声明】 —— 原内容里的"存疑/未找到/非鉴定"等提示**必须保留**
```

## 三、硬约束

1. **不新增事实**：不得引入原文与出处之外的任何事实性陈述；
2. **不改变结论**：原文说"存疑"，适配后**仍须存疑**；
3. **不丢弃边界声明**：`未找到 / 存疑 / 非鉴定 / 非估价` 等标记**必须随文保留**；
4. **压缩即舍弃**：因篇幅删掉的句子，其出处一并标注为"未纳入本次输出"，**不得让其看似仍被支持**；
5. 画像不明 → **问，不猜**。

## 四、与其他 skill 的关系

```
exhibit-narrative（产生内容与出处）
        ↓
audience-adapter（换表达，不动事实）   ← 本 skill
        ↓
source-verifier（校验适配后是否仍句句有据）
```
**三者可任意组合**，这正是"Skills 设计与融合"的体现。
