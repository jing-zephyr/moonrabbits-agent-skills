# exhibit-narrative · 展品叙事官

> **SKILL.md 是路由表，不是百科。** 细节按需读 `references/`，重型操作用 `scripts/`。

## 一、触发判定（先做这个）

**触发**（满足任一）：
- 输入含**展品图像**，且用户要求讲解、生成卡片、写看展笔记；
- 输入含**展品名称 + 馆藏/年代线索**，且用户要求讲述或整理；
- 用户显式点名"五色五季"框架。

**不触发 → 直接回退**（不要勉强套用）：
- 风景/人物/动物等**非展品**图像 → 说明"本 skill 只处理展品"；
- **鉴定 / 估价 / 交易 / 投资**类诉求 → **明确拒答**，说明不提供此类服务；
- 纯技术/闲聊任务 → 交回默认进程。

**关键参数不全 → 先问，不许猜**：
- 图像不清晰 / 无法判断是否为展品 → **问用户**；
- 缺少馆藏或年代线索而用户又要求"准确年代" → **说明只能给知识库支持的区间**，不硬报年代。

## 二、调度链（四专家协同 + 冲突校验 + 三角色质检）

```
① 前置检查（图像可用？是否展品品类？参数够不够？）
      ↓ 不通过 → 先问用户
② 知识库检索（scripts/kb_search.py）—— 只从库取事实
      ↓ 命中为空 → 走 §四 拒答分支
③ 四专家协同
      ├─ 考据官：原文出处、年代/窑口/工艺事实
      ├─ 格物官：器型/釉色/纹饰/款识的形式分析
      ├─ 灵感官：与五色五季框架、观众画像的连接
      └─ 讲述者：成文（风格由 audience-adapter 决定）
④ 冲突校验（scripts/verify_sources.py + source-verifier skill）—— 必经闸门，不是建议
      ├─ 年代差 > 50 年且并存 → 两条都列，标注存疑
      ├─ 置信度差 > 0.3 → 触发二次验证
      ├─ 证据分 < 0.6 → **直接拒答，禁止进入下一步**（fail-closed 执行化）
      └─ 受众权重矩阵 → 决定详略
⑤ 三角色质检（SignalForge 三思想之质量保障角色）
      ├─ 批评者 critics：逐句挑无出处句、矛盾句、越界句
      ├─ 修复者 repair：对挑出的问题逐条改写或补出处
      └─ 审查者 reviewer：复核签字后才放行；不签字 = 打回重走④⑤
⑥ 输出契约（见 §三）
```

**可组合调用**：
- 需要按观众调整 → 调 **`audience-adapter`**；
- 需要独立校验出处 → 调 **`source-verifier`**。

## 三、输出契约（**必须严格遵守**）

返回**四段**，顺序固定：

```
【叙事正文】   —— 可直接展示给观众的成文
【出处列表】   —— 逐条：来源名 / 作者 / 出版方 / 置信度 / 对应哪一句
【置信度】     —— 整体置信度 + 哪几处属"低置信/存疑"
【使用提示】   —— 本叙事的边界（非鉴定、非估价、以馆方为准）
```

**机器可读字段**（保持既有结构，便于前端复用）：
```json
{ "title": "", "subtitle": "", "content": "",
  "tags": [],
  "sources": [{"name":"","author":"","publisher":"","confidence":0,"note":""}],
  "trustNote": "不编造 · 不越界 · 不替代" }
```

## 四、硬约束（写死在 skill 里，不靠临时提醒）

1. **每一句必须有出处**；检索不到 → **明确说「知识库未找到」**，**绝不编造**（fail-closed）；
2. **不推断**真伪、价格、来历、投资价值；
3. **不复制**展签/图录原文（版权）——只提取事实，叙事文本**原创生成**；
4. **不打印**任何明文 token / 密钥 / 内网地址；
5. **不改动** checked-in 配置或用户原始文件；
6. 不处理**非展品类**图像。
