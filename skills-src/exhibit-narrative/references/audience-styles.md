# 观众画像 · 风格与详略参考

> 供 `audience-adapter` 使用。**原则：只换表达，不换事实。**

## 一、四个画像

### 1. 儿童（6–12 岁）
- **句长**：短句，一句一个意思
- **词汇**：少术语；必须用术语时给**具象比喻**（如"釉面像凝固的猪油一样润"）
- **篇幅**：短（3–5 句为宜）
- **结构**：先"是什么/长什么样" → 再"谁做的/什么时候" → 最后"为什么好看"
- **禁区**：不涉暴力、死亡、交易价格、真伪判断

### 2. 普通观众（默认）
- **句长**：中等
- **词汇**：平实、有画面感；术语**首次出现给一句解释**
- **篇幅**：中（可含 1–2 段）
- **结构**：器物的"看点" → 背后的时代/工艺 → 与今天的连接
- **禁区**：不作绝对化断言（"最珍贵""唯一"等需来源支撑）

### 3. 专业观众
- **词汇**：可直接使用术语（窑口、釉色、支烧、款识、胎釉结合等）
- **内容**：给年代区间、窑口、工艺参数、款识信息
- **篇幅**：长
- **要求**：**每个事实性陈述都要能指向出处**
- **禁区**：不夸大、不臆断；争议点必须双列

### 4. 外语观众
- **语言**：目标语言
- **文化专名**：需处理（音译 + 简短解释，或保留中文 + 括注）
- **必须保留**：原文中的 `存疑 / 未找到 / 非鉴定 / 非估价` 等边界标注
- **禁区**：不因翻译而弱化不确定性

## 二、篇幅档位

| 档 | 用途 | 参考长度 |
|---|---|---|
| **一句话** | 分享卡片标题 | 15–30 字 |
| **展签** | 展品旁说明 | 80–150 字 |
| **短讲述** | 小程序卡片/看展笔记 | 200–400 字 |
| **讲解稿** | 语音讲解/视频脚本 | 600–1200 字 |

**压缩规则**：因篇幅删掉的句子，**其出处一并标注"未纳入本次输出"**——不得让其看似仍被支持。

## 三、输出时必须附的三项（供 `source-verifier` 接力）

1. 【本次做了什么】改了语气/详略/术语解释；
2. 【沿用/舍弃的出处】—— 舍弃了哪些句子，对应哪些出处；
3. 【保留的边界声明】—— 逐条列出仍保留的"存疑/未找到"标注。
